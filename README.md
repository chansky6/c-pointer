## 转换脚本

直接文本提取工具（如 markitdown）对这本书效果不佳：结构信息全部藏在字体与坐标里。`pdf2md.py` 基于 `pdftohtml -xml` 的中间输出重建排版：

- 字体驱动分类：黑体/大字号 → 标题，Courier → 代码块，行内 Courier/SimHei → `` `代码` `` / `**加粗**``
- 代码块跨页合并、按像素坐标恢复缩进，折行的中文注释经 `/* ... */` 状态机吸收回代码块
- 原书 ASCII 内存图混用 Times/Courier 按比例排版，直接拼接会错位，脚本按像素重投影到等宽网格
- 段落按缩进、空行、句末标点规则跨页拼接，并自动生成目录

使用（依赖 poppler 的 `pdftohtml`）：

```bash
python3 pdf2md.py "彻底搞定 C 指针.pdf" 彻底搞定C指针.md
```

启发式规则针对本书调校，用于其他 PDF 需自行调整。
